    Foundations
    Iconography
    
        
    Line icons on a 24px grid, ~1.8–2px stroke, rounded caps — one weight so icons and type read as one system.
    
        
    
      
    

      
      
    
        
    Guidance
    Do & Don't
    
        
    
          
    ✓ Do
      
            
    • Keep green as the single ownable accent — spend it on momentum and wins.
      • 
            
    • Pair the wordmark's two-tone treatment consistently (ink + green).
      • 
            
    • Keep surfaces calm so the user's funnels are the hero.
      • 
            
    • Use tinted pills (text + soft bg + dot) for every status.
      • 
          
    
          
    ✕ Don't
      
            
    • Add a second brand color or a display font.
      • 
            
    • Recolor, stretch, or add effects to the logo.
      • 
            
    • Use hype language or exclamation-heavy copy.
      • 
            
    • Use pure-black text or heavy drop shadows.
